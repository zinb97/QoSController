# 常见的 DSCP 值

| DSCP值 | 十进制 | 名称                      | 使用场景                   |
| ------ | ------ | ------------------------- | -------------------------- |
| 000000 | 0      | Default Forwarding (DF)   | 默认流量，没有特殊处理     |
| 001000 | 8      | Class Selector 1 (CS1)    | 低优先级的数据流           |
| 001100 | 12     | Class Selector 2 (CS2)    | 低优先级的语音或视频流     |
| 010000 | 16     | Class Selector 3 (CS3)    | 中等优先级的流量           |
| 010100 | 20     | Class Selector 4 (CS4)    | 适合信号控制或远程操控流量 |
| 011000 | 24     | Class Selector 5 (CS5)    | 高优先级的语音和视频流     |
| 101010 | 34     | Assured Forwarding (AF)   | 中等优先级，适用于业务流量 |
| 011100 | 28     | Class Selector 6 (CS6)    | 高优先级的保证型流量       |
| 101110 | 46     | Expedited Forwarding (EF) | 实时语音流，极高优先级     |
| 111111 | 63     | Class Selector 7 (CS7)    | 保留，用于网络管理流量     |
